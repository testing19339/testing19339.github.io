☁️ Proton Drive

Connect your Proton Drive to access Cryptomator vaults stored there.

Option 1 — iPhone / iPad (recommended)
Proton Drive is integrated into the iOS Files app.
Tap "Open vault" → browse to Proton Drive in Files → select your vault folder. Everything decrypts locally.
Option 2 — Desktop (Chrome / Edge)
1. Open drive.proton.me
2. Download your vault folder as a zip
3. Extract it, then use "Open vault" to select the folder
Option 3 — Direct API (advanced)
Paste your Proton session UID + Access Token from browser DevTools → Configure token access
